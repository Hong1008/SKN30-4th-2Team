# WorkShield 기능 요구사항 명세서

WorkShield 시스템의 기능 및 비기능 요구사항을 도메인 단위로 분리하여 관리하는 메인 명세서입니다.

---

### 1. 계약서 입력 & 유형 확인 (`FR-1`)
* **파일**: [01_contract_input_and_type.json](./ref/01_contract_input_and_type.json)
* **주요 내용**:
  * 지원 형식: HWP, HWPX, PDF, DOCX
  * 프론트/백엔드 사전 검증 (손상, 암호화, 빈 문서, 10MB 크기 제한 차단)
  * SW 프리랜서, SI 하도급, SM 하도급 3가지 지원 유형 후보 분석 및 사용자 직접 확정

### 2. 검토 진행 상황 (`FR-8`)
* **파일**: [02_review_progress.json](./ref/02_review_progress.json)
* **주요 내용**:
  * 단계별(준비 → 검색 → 선별 → 조항비교 → 포함여부 → 결과정리) 서버 진행 이벤트 수신
  * 프론트엔드 임의 타이머 금지 및 2~3초 간격 API Polling/SSE 보조 연동

### 3. 표준 대비 검토 결과 (`FR-2`)
* **파일**: [03_review_results.json](./ref/03_review_results.json)
* **주요 내용**:
  * 최상위 `status` 해석 우선 법칙 (`results` 배열 비어있음으로 문제없음 단정 금지)
  * `NONE`, `EXTRA`, `NO_MATCH` 상태 매핑 및 탐색 필터 지원
  * 법적 단정(위법/합법, 승소 등) 지양 안내

### 4. 주의 문구 후보 & 표준 체크리스트 (`FR-3`, `FR-4`)
* **파일**: [04_risk_and_checklist.json](./ref/04_risk_and_checklist.json)
* **주요 내용**:
  * **주의 문구 후보**: 불공정 패턴(toxic patterns)을 별도 독립 영역에 표시
  * **표준 체크리스트**: 대응 조항을 찾지 못한 표준 조항(`MISSING`)을 체크리스트로 관리하고 `standard://` 리소스 원문 조회 제공

### 5. 검토 결과 기반 AI 챗봇 (`FR-5`)
* **파일**: [05_chatbot_qa.json](./ref/05_chatbot_qa.json)
* **주요 내용**:
  * 현재 계약서/검토 결과/법령 데이터 한정 QA 및 출처(Sources) 필수 검증
  * 범위 밖 질문 거절(`refused`), 환각 및 프롬프트 인젝션 방지

### 6. 수정·협의 문구 제안 (`FR-6`)
* **파일**: [06_clause_proposal.json](./ref/06_clause_proposal.json)
* **주요 내용**:
  * 원문-표준 조항 비교 기반 참고용 대안 문구 생성
  * 미확정 금액/기간 `[확인 필요]` 표시, 단일 제안 복사, 원본 문서 자동 수정 금지

### 7. 보안, 세션 & 인프라 운영 정책 (`FR-7`)
* **파일**: [07_security_and_infrastructure.json](./ref/07_security_and_infrastructure.json)
* **주요 내용**:
  * 세션 기반 접근 제한 및 영구 저장 금지 (30분 TTL 후 임시 데이터 정리)
  * TLS 구간 전송 암호화, 로그 마스킹 (원문/대화 내용 로그 기록 금지)
