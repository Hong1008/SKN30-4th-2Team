# Requirements & Specifications

요구사항 ID를 API, 화면, 테스트 케이스에 연결하는 추적표 및 관련 설계 문서를 보관합니다.

## 핵심 요구사항 문서 구조

- **서비스_전체_흐름도.json**이 백엔드/시스템의 근본적인 상태 머신 규칙을 규정하면,
- **사용자 흐름·상태 정의서 초안.md**는 이를 기반으로 기획 정책 및 사용자 관점의 서비스 경험으로 해석하고,
- **개발협업용_화면설계서_초안.md**는 이를 바탕으로 실제 구현될 화면 UI/UX와 API 데이터 통신 스키마로 구체화한 구조입니다.
