## 1. 결과 요약

| 항목 | 값 |
| --- | --- |
| 계획 케이스 | 13건 (`DEMO-00`~`DEMO-12`) |
| 실행 케이스 | 0건 |
| PASS / FAIL / 미실행 | 0 / 0 / 13 |
| 실행 완료율 | 0% |
| 발표 시연 판정 | 미판정 |

> 실행 후 각 수치를 갱신한다. 안전한 오류 주입 수단이 없는 `DEMO-05`, `DEMO-12`는 사유와 우회 시연 경로를 남긴 뒤 미실행으로 기록할 수 있다.

## 3. 시연 입력값

계획서에서 지정한 입력값을 실제 실행 전에 확정해 기록한다. 계약서 원문·조항 전문·개인정보·대화 전문은 기록하지 않는다.

| 구분 | 식별명 또는 입력값 | 기대 확인 사항 |
| --- | --- | --- |
| 정상 시연 PDF | `<식별명>` | 업로드 → 유형 선택 → 결과 → 챗봇 → 협의 문구 정상 흐름 |
| 오류용 파일 | `<빈 문서 또는 미지원 파일 식별명>` | 업로드 차단·재업로드 안내 |
| 챗봇 정상 질문 | `<질문 문구>` | 답변, 제한사항, 사용자용 출처 표시 |
| 챗봇 거절 질문 | `<질문 문구>` | 범위 밖 또는 근거 부족 거절 |
| 기본 지시문 방어 질문 | `<질문 문구>` | 문서 지시문 미이행·거절 |
| 협의 문구 대상 조항 | `<조항 식별명>` | 근거 기반 단일 초안·복사·작성 근거 표시 |
| 근거 부족 조항 또는 요청 | `<식별명>` | 문구 미생성·확인 필요 안내 |

| --- | --- | --- | --- | --- | --- | --- | --- |

| DEMO-02 | 빈 문서·업로드 오류 | FR-1-2, FR-1-8; `file_mcp.upload_validation`, `review_state.empty_document` | 검토 시작 차단 및 재업로드 안내 |  | 미실행 |  |  |
