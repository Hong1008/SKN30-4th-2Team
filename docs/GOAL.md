# 📌 4차 단위 프로젝트

## 주제

**LLM을 연동한 내·외부 문서 기반 질의응답 웹페이지 개발**

## 목표

* 웹페이지 개발을 위한 요구사항 정리 및 화면 설계
* HTML, CSS, JavaScript 기반 프론트엔드와 FastAPI 기반 백엔드 개발을 통한 Web Application 구축
* LLM 연동 기능을 추가한 Web Application 구현
* 클라우드 활용 인프라 구축 및 클라우드 환경에서 LLM 연동 Web Application 배포

## 내용

* 프로젝트의 목표와 사용자의 요구사항을 분석하고 문서화
* 시스템 구성도 설계
* 웹페이지 구축을 위한 백엔드 API 개발
* 웹사이트의 구조, 레이아웃, 색상, 아이콘 등을 화면 설계
* HTML, CSS, JavaScript를 활용한 프론트 웹페이지 구현
* 클라우드에 인프라 구성
* 클라우드/온라인에 데이터 Migration 및 코드 배포
* 프론트엔드, 백엔드, LLM, DB 연동
* 통합 테스트 진행 및 결과 보고서 작성

## 필수 산출물

* 요구사항 정의서
* 화면설계서
* 개발된 LLM 연동 웹 애플리케이션
* 시스템 구성도
* 테스트 계획 및 결과 보고서
